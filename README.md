# AstroPhase: Interactive Lunar Calendar & Eclipse Simulator

## Purpose
AstroPhase is an educational science demo and interactive astronomical calculation tool. It allows users to explore lunar phases, illumination percentages, orbital dynamics, moon distance, and eclipse conditions for any date.

## Features
- **Orbital Alignment Simulator**: Top-down canvas visualization showing the relative positions of the Sun, Earth, and Moon.
- **Detailed Moon Phase Renderer**: Procedural HTML5 canvas rendering exact illumination terminator curves for any given day.
- **Time Control & Scrubbing**: Interactive date picker, day-offset slider (-30 to +30 days), and animated time-lapse playback.
- **Synodic Cycle Calendar**: Quick-access grid showing key lunar phases (New Moon, First Quarter, Full Moon, Last Quarter) relative to the selected date.
- **Eclipse Alerts**: Real-time logic checking orbital nodes for potential solar or lunar eclipse conditions.
- **Dynamic Science Notes**: Educational blurbs tailored to the active moon phase.

## Local Run Instructions
1. Download or clone the project files (`index.html`, `style.css`, `script.js`, `README.md`).
2. Open `index.html` in any modern web browser.
3. Enjoy exploring lunar cycles offline!

## Technical Note
This is a fully static front-end web project built with vanilla HTML5, CSS3, and JavaScript with zero external dependencies or network requests.
